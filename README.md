A Python program that draws one open passport spread of the Republic of
Velmora, a country that does not exist: a bilingual data page with a drawn
portrait and ghost image, a coat of arms, an ICAO 9303 machine-readable zone
with genuine check digits, a Brezna multiple-entry visa with its consular fee
stamp, and a chain of border stamps (Kessig exit, Brezna entry and exit,
Ossary arrival by sea) whose dates all agree with the passport's own issue
date. The observations page records the one detail that gives the country
away: its bearer, a lighthouse keeper, is exempt from harbour dues in all
Velmoran ports. Output is a single 1024x728 PNG written to /output/entry.png.

## Run it

```sh
python3 main.py
```
